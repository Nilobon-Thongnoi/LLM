=== QUESTION ===
(20 คะแนน) จงสร้างฟังก์ชันเพื่อคำนวณอัตราภาษีรถยนต์นั่งส่วนบุคคลรายปี โดยวิธีการคำนวณภาษีดังกล่าวมีดังต่อไปนี้

อัตราภาษีจะคำนวณอ้างอิงจากขนาดความจุของกระบอกสูบ (CC)
• ตั้งแต่ 1-600 cc คิดอัตราภาษี cc ละ 0.5 บาท
• ตั้งแต่ 601-1,800 cc คิดอัตราภาษี cc ละ 1.5 บาท
• ตั้งแต่ 1,801 cc ขึ้นไป คิดอัตราภาษี cc ละ 4 บาท

ตัวอย่างการคำนวณภาษีรถยนต์ Toyota Camry รุ่น 2.0 cc (2000 cc)
• 600 cc แรก อัตราภาษี -> 600 x 0.5 = 300 บาท
• 601-1,800 cc อัตราภาษี -> (1,800 - 600) x 1.5 = 1,800 บาท
• ส่วนเกินจาก 1,800 cc อัตราภาษี -> (2,000 - 1,800) x 4 = 800 บาท
รวมอัตราภาษีที่ต้องจ่ายรายปี เท่ากับ 300 + 1,800 + 800 = 2,900 บาท

เงื่อนไขในการสร้างฟังก์ชัน ได้แก่
• จำเป็นต้องรับพารามิเตอร์ ได้แก่ ค่าความจุของกระบอกสูบรถยนต์ (CC)
• ผลลัพธ์ที่ได้จากฟังก์ชันคือ จำนวนเงินภาษี ซึ่งมีชนิดข้อมูลเป็นเลขจำนวนเต็ม (Integer)

=== REFERENCE_ANSWERS ===
--- แบบ if-else ---
function calculateCarTax(cc) {
  let tax = 0;

  if (cc <= 600) {
    tax = cc * 0.5;
  } else if (cc <= 1800) {
    tax = 600 * 0.5 + (cc - 600) * 1.5;
  } else {
    tax = 600 * 0.5 + 1200 * 1.5 + (cc - 1800) * 4;
  }
  return Math.round(tax);
}
console.log(calculateCarTax(2000));

--- แบบ switch (อาจารย์ยอมรับ) ---
function taxCalculate(carCC) {
  totalTax = 0;
  switch(carCC){
    case
      (carCC <= 600): totalTax = carCC * 0.5;
      break;
    case
      (carCC >600 && carCC <= 1800): totalTax = (600 * 0.5) + ( (carCC - 600) * 1.5);
      break;
    default:
      totalTax = (600 * 0.5) + (1200 * 1.5) + ( (carCC - 1800) * 4);
  }
  console. log("Total Tax: "+ parseInt(totalTax)) ;
}
taxCalculate(2000);

=== RUBRIC ===
C1 | Declare a function with a single parameter (cc) | 4 | 2 สำหรับฟังก์ชัน + 2 สำหรับพารามิเตอร์
C2 | Condition statement if-else หรือ switch-case ครบ 3 กรณี | 6 | 2 ต่อกรณี
C3 | Correct tax calculation ครบ 3 กรณี | 6 | 2 ต่อกรณี
C4 | Display / return the output | 2 |
C5 | Convert the output to Integer | 2 |

=== RULES ===
- C1: 2 คะแนนสำหรับประกาศฟังก์ชัน + 2 คะแนนสำหรับมีพารามิเตอร์ตัวเดียวที่รับค่า cc
- C2: 2 คะแนนต่อกรณี (<=600, 601-1800, >1800) ถ้ากรณีนั้นไม่มีเงื่อนไขหรือ branch รองรับ ให้ 0 ของกรณีนั้น
- C3: 2 คะแนนต่อกรณี ถ้าสูตรของกรณีนั้นให้ผลผิดจากค่าที่ถูกต้อง ให้ 0 ของกรณีนั้น
  - ค่าที่ถูกต้อง: 500->250, 600->300, 601->301.5 (301 หรือ 302), 1800->2100, 1801->2104, 2000->2900
  - กรณี <=600 ดูที่ 500 และ 600, กรณี 601-1800 ดูที่ 601 และ 1800, กรณี >1800 ดูที่ 1801 และ 2000
- C4: return หรือ console.log ผลลัพธ์ ถือว่าแสดงผลทั้งคู่
- C5: parseInt, Math.round, Math.floor, Math.trunc ถือว่าแปลงเป็น integer ถ้าไม่มีการแปลงเลย ให้ 0
- เฉลยแบบ switch ที่อาจารย์ให้ถือว่าถูกตามเจตนา คำตอบที่ใช้ switch ลักษณะเดียวกันให้ตัดสินจากเจตนา ไม่ตัดสินจากผลการรัน
